# First FMCG ⇄ Crate — تحليل تفصيلي + خارطة تبنّي الميزات

> تاريخ: 2026-08-05. المصدر: خصائص firstfmcg.com المعلنة + الحالة الفعلية لـ Crate.
> الهدف: مقارنة قدرة-بقدرة، ثم ما الذي نَنقله إلى Crate ولماذا وكيف — ضمن قيود Crate (Vercel FREE بكرونين، رصيد Anthropic، Supabase).

## 1. ملخّص تنفيذي
First FMCG = سوق جملة FMCG أوروبي مدعوم بالـAI، **حديث (أبريل 2026)، فردي، صغير الحجم لكن حديث الأفكار**. قوّته في **تجربة البحث الذكي + التكلفة الواصلة + التكامل مع مساعدات الـAI**. Crate يتفوّق في **عمق الامتثال الإماراتي + توليد الملصق المطابق + الدروبشيب للطباعة** — أشياء لا يقدّمها هو. فهو **مصدر إلهام للتجربة، لا منافس مباشر في سوقك**.

## 4. البحث بالـAI على Crate — كيف ننفّذه **رغم قيد الرصيد** (تفصيل)

المشكلة: نداء LLM لكل استعلام يكلّف رصيداً + بطئاً، ورصيد Crate نفد. الحل = **معمارية 3 طبقات متدرّجة** (نفس نمط الـfallback المجاني للسكانر الذي بنيناه):

**الطبقة 1 — محلّل حتمي (مجاني، دائماً):** استخرج من الجملة: الكمية + كلمات المنتج + الوجهة + الإنكوتيرم عبر regex + خريطة مرادفات/فئات → فلتر منظّم → استعلام Supabase full-text على `products`/`providers`. **هذه وحدها تعطي ~80% من القيمة مجاناً.** (Crate عنده أصلاً بحث خادمي للموردين — نوسّعه للجهة العامة.)

**الطبقة 2 — دلالي رخيص (اختياري):** احسب embeddings للمنتجات/الموردين **مرّة واحدة** (تكلفة ضئيلة أو نموذج مجاني)، ثمّ طابق embedding الاستعلام للترتيب الدلالي. الـembeddings **أرخص بكثير** من نداءات المحادثة، ونداء واحد لكل بحث.

**الطبقة 3 — تحسين LLM (مشروط بالرصيد، متدرّج):** عند توفّر رصيد Anthropic، استخدم Claude لتفسير الاستعلامات الغامضة + كتابة ملخّص طبيعي للنتائج. **عند غياب الرصيد يتحوّل تلقائياً للطبقة 1** (لا يخطئ، مثل السكانر).

**الجدوى:** بحث عند الطلب (لا cron)، خادمي على Supabase → متوافق مع Vercel FREE. **يبدأ مجانياً بالكامل** (طبقة 1)، ويتحسّن حين يتوفّر الرصيد.

## 5. تفصيل الميزات الأخرى
- **التكلفة الواصلة (حتمي):** Crate عنده حاسبات تعبئة/كراتين. أضِف جدول شحن/رسوم تقديري لكل وجهة إماراتية → «سعر واصل تقديري» بجانب كل عرض. بلا AI.
- **أداة باركود عامة:** السكانر موجود — أخرِج نسخة عامة خفيفة «باركود → ما نعرفه + فحص امتثال سريع» كأداة مجانية قابلة للمشاركة (SEO/lead-gen). تعيد استخدام ما بُني.
- **AEO+ (MCP/API عام):** أنجزنا llms.txt/schema/robots-AI. الخطوة التالية: **نقطة API عامة (أو MCP)** تتيح لـChatGPT/Claude الاستعلام عن امتثال/منتجات Crate مباشرة — تمييز قوي ورخيص.
- **الطلب المجهول:** طبقة فوق RFQ القائم: إخفاء هوية الطرفين حتى قبول العرض → يبني ثقة المورّدين المتردّدين.

## 6. التوصية (الترتيب)
1. **البحث الهجين (طبقة 1 المجانية أولاً)** — أكبر فجوة، يبدأ بلا رصيد.
2. **حاسبة التكلفة الواصلة** — حتمية، تناسب هوية الاستيراد.
3. **أداة الباركود العامة** — طُعم SEO سريع يعيد استخدام السكانر.
4. **AEO+ (API/MCP عام)** — تمييز عن الجميع، رخيص.
5. لاحقاً: الطلب المجهول + الاشتراكات.

**المبدأ:** انقل **التجربة** (بحث ذكي، تكلفة واصلة، طُعم مجاني، تكامل AI) مع الحفاظ على **خندقك** (الامتثال + الملصق + الدروبشيب) الذي لا يملكه هو — فتجمع أفضل الاثنين.
